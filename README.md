# RentalGameZone
# Sistem Rental PlayStation "GameZone"

## Deskripsi Singkat
Aplikasi console Java ini dibuat untuk membantu petugas tempat penyewaan PlayStation "GameZone" dalam menghitung biaya penyewaan konsol (PS4/PS5), memproses diskon durasi sewa, menambahkan opsional minuman, serta menampilkan struk rincian pembayaran pelanggan secara otomatis.
## Fitur Utama
1. **Input Data Pelanggan**: Mencatat nama pelanggan secara fleksibel.
2. **Pilihan Konsol**:
   - PlayStation 4 (Rp 8.000 / jam)
   - PlayStation 5 (Rp 12.000 / jam)
3. **Diskon Otomatis**: Diskon sebesar 10% dari total biaya sewa jika lama bermain minimal 3 jam.
4. **Opsional Minuman**: Tambahan biaya Rp 5.000 untuk opsi pembelian minuman.
5. **Method Pemrograman**: Perhitungan biaya menggunakan *method* terpisah `hitungBiayaSewa()`.
6. **Perulangan Transaksi**: Fitur untuk memproses transaksi baru tanpa perlu menjalankan ulang aplikasi.
